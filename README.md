# レコードApp

Windows で会議音声を録音し、録音フォルダや動画を文字起こしする Python GUI アプリです。
マイク音声と相手音声を分けて保存し、用途に応じた文字起こしパターンを選べます。

## 主な機能

- マイク音声と相手音声の録音
- 録音中メモの保存と文字起こしテキストへの追記
- 録音フォルダをキューに追加して文字起こし
- 動画ファイルを追加して文字起こし
- ローカル Whisper モデルと OpenAI API モデルの使い分け
- OpenAI API を使った話者分離対応パターン

## 必要な環境

- Windows
- Python
- `ffmpeg`
- Python パッケージ
  - `pyaudiowpatch`
  - `faster-whisper`

`tkinter` は GUI に使用します。利用する Python 環境で `tkinter` が使えることを確認してください。

## セットアップ

依存パッケージをインストールします。

```powershell
python -m pip install pyaudiowpatch faster-whisper
```

動画の音声抽出と一部の音声変換で `ffmpeg` を使います。
`ffmpeg` コマンドを実行できるように PATH を設定してください。

OpenAI API モデルを使う場合は API キーが必要です。
`OPENAI_API_KEY` 環境変数が設定されている場合はその値を優先し、未設定の場合は設定画面から入力できます。

## 起動

```powershell
python .\録音.py
```

## 使い方

### ホーム

相手音声デバイスとマイクを選び、録音を開始します。
録音中は音量レベルを確認でき、メモも入力できます。
メモは文字起こし完了後に出力テキストへ追加されます。

### 分析

録音フォルダまたは動画を文字起こしキューへ追加し、文字起こしを開始します。
録音フォルダ追加時は内容に合うパターンを選びます。

| パターン | 用途 | 使用モデル |
| --- | --- | --- |
| オンラインMTG: 自分 + 相手1人 | 1対1のオンライン会議 | 自分: `large-v3` / 相手: `gpt-4o-transcribe` |
| オンラインMTG: 自分 + 相手複数 | 相手側に複数人いるオンライン会議 | 自分: `large-v3` / 相手: `gpt-4o-transcribe-diarize` |
| オフラインMTG: 自分マイクのみ | 1本のマイクに複数人の声が入る対面会議 | マイク音声: `gpt-4o-transcribe-diarize` |
| マニュアル | 設定画面のモデル選択を使う文字起こし | 設定画面で選択したモデル |

OpenAI API モデルを使うパターンでは API キーが必要です。

### 設定

文字起こしモデル、処理モード、OpenAI API キー、固有名詞・専門用語を設定します。
マニュアルパターンと動画文字起こしでは、ここで選んだモデル設定を使います。

ローカルモデルで精度を重視する場合は `large-v3` がおすすめです。
会社 PC など低スペックな環境では、`large-v3` の処理に録音時間と同程度かかる場合があります。

「固有名詞・専門用語」欄には、会議でよく出る固有名詞や専門用語をカンマ区切りで入力できます。
入力した語はローカルモデルには `initial_prompt`、OpenAI API には `prompt` として渡され、
固有名詞の誤変換や言語（日本語／英語）の取り違えを減らすヒントになります。

## 出力

実行した作業フォルダの `mtg_records/` に録音結果を保存します。
録音ごとに日時ベースのフォルダが作られ、音声ファイル、文字起こし結果、エラーログなどを保存します。
